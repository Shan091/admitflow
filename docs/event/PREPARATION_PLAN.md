# AdmitFlow execution and demonstration checklist

Use the existing [implementation plan](../../tasks/plan.md),
[task list](../../tasks/todo.md) and [specification](../../SPEC.md).
The active stack is Telegram + OpenAI with the existing Python/data/worker foundation.
This checklist supports execution; it is not an additional product roadmap.

## Build and verify

- [ ] Complete the selected task with acceptance evidence and update tasks/todo.md.
- [x] Demonstrate real Telegram intake/worker/reply with handset confirmation.
- [x] Verify course/batch callbacks, memory/corrections and code-owned eligibility in database journey tests.
- [x] Verify grounded/unsupported FAQs and source references in synthetic journey/provider checks.
- [x] Verify authenticated staff visibility and tenant isolation, including the persisted live inquiry.
- [x] Verify human-request controls in database journey tests and the real staff browser
  against the user-sent `/human`: acknowledgment, resolution with pause and explicit resume.
- [x] Run the repository gate and applicable database/Redis/frontend checks.
- [x] Record the exact tested build, failures, limitations and usage in tasks/todo.md and BUILD_MANIFEST.json.

## Demonstrate and submit

- [ ] Confirm organizer permission for disclosed prior work and any surprise requirement.
- [ ] Confirm the current portal, deadline and upload requirements from original sources.
- [x] Use synthetic institution/student data and label it clearly.
- [x] Save and visually inspect the actual local staff walkthrough recording.
- [ ] Rehearse the student-to-staff journey and record the final working build.
- [ ] Finish the README/demo link, deck and AI Impact Statement.
- [ ] Check judge access to every link and upload with a buffer.

Event schedules remain in [original sources](SOURCES.md). This active checklist uses
milestone completion rather than calendar promises. Historical Meta restrictions and
prior test results remain in [READINESS_CHECK.md](READINESS_CHECK.md); they do not
establish Telegram readiness. No organizer contact or submission is implied here.
